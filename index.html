안국, 걸어서 하루

2026년 10월 5일 월요일
개천절 대체공휴일 — 북촌·익선동 인파 많음, 예약 권장

필동 점심에서 출발해 안국역 일대 카페·간식·소품샵·저녁을 도보로 잇는 코스입니다. 아래에서 가게를 고르면 지도의 동선과 시각별 위치가 바로 다시 계산됩니다. 영업시간은 월요일 기준이며 공휴일에는 바뀔 수 있어 당일 확인을 권합니다.

오늘의 일정

    전체 도보 경로 Google 지도에서 열기

    필동 → 안국 이동 12:00 출발

    전자방 필동점에서 충무로역까지 걸어가 3호선으로 세 정거장이면 안국역입니다.

    감성 카페 13:00 – 15:00

    하나를 고르세요. 북촌 쪽은 안국역에서 2~5분, 익선동 쪽은 8~10분 거리입니다.

    간식 — 핫도그 15:00 즈음

    안국역 반경 안에 핫도그 전문점은 많지 않습니다. 가까운 순으로 정리했고, 가는 길의 노점 핫도그도 대안입니다.

    소품샵 구경 16:00 – 18:00

    2~3곳을 고르면 가장 짧은 순서로 자동 정렬되고, 체류 시간이 저녁 시간에 맞춰 배분됩니다.

    저녁 식사 18:00

    1순위 선채 안국점은 Google 지도에 등록돼 있지 않아 안국역 기준 임시 좌표로 표시했습니다. 네이버 지도에서 정확한 위치와 예약을 확인하세요.

    지도는 Google 지도(본인 API 키) 또는 OpenStreetMap 위에 실제 위도·경도로 표시되며, 둘 다 불러올 수 없는 환경에서는 같은 좌표의 약도로 바뀝니다. API 키는 이 브라우저에만 저장됩니다. 길 안내는 각 장소의 카카오맵·Google 링크를 이용하세요. 도보 시간은 직선거리 ×1.3, 시속 4.2km 기준 추정치입니다.
